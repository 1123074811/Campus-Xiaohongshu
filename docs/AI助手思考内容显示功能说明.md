# AI助手思考内容显示功能说明

## 功能概述

为AI助手添加了思考过程的特殊标识和显示控制功能，用户可以选择是否查看AI的思考过程。

## 功能特点

### 1. 思考内容标识
- AI在回答问题时，会将思考过程用 `<thinking>` 标签包围
- 思考内容包括分析、推理、考虑等内部处理过程
- 最终回答会在思考内容之后给出

### 2. 显示控制
- 用户可以通过聊天界面右上角的开关控制是否显示思考内容
- 开关状态会保存到本地存储，下次访问时自动恢复
- 切换显示状态时，所有消息会立即更新

### 3. 特殊样式
当显示思考内容时，会使用特殊的视觉样式：
- 浅蓝色背景的标题栏，显示"🤔 AI思考过程"
- 白色背景的内容区域
- 左侧蓝色边框标识
- 斜体文字样式
- 圆角边框和阴影效果

## 技术实现

### 后端实现 (Spring Boot)

#### 1. 增强提示词
在 `AiChatServiceImpl.java` 中添加了 `buildEnhancedPrompt` 方法：

```java
private String buildEnhancedPrompt(String userMessage) {
    return """
            请在回答问题时，将你的思考过程用特殊标识包围。
            
            使用格式：
            <thinking>
            这里是你的思考过程，包括分析、推理、考虑等内容
            </thinking>
            
            然后给出你的最终回答。
            
            用户问题：%s
            """.formatted(userMessage);
}
```

#### 2. 流式处理
- 修改了 `chatStream` 方法，使用增强的提示词
- 添加了 `processAiChunk` 方法用于处理AI回复块
- 保持流式响应的实时性

### 前端实现 (Vue 3)

#### 1. 显示控制开关
在聊天界面头部添加了开关组件：

```vue
<div class="thinking-control">
  <el-switch
    v-model="showThinking"
    size="small"
    active-text="显示思考"
    inactive-text="隐藏思考"
  />
</div>
```

#### 2. 消息格式化
在 `formatMessage` 方法中添加了思考内容的处理逻辑：

```javascript
const thinkingRegex = /<thinking>([\s\S]*?)<\/thinking>/g

if (showThinking.value) {
  // 显示思考内容，添加特殊样式
  processedContent = content.replace(
    /<thinking>([\s\S]*?)<\/thinking>/g,
    '<div class="thinking-content">...</div>'
  )
} else {
  // 隐藏思考内容
  processedContent = content.replace(/<thinking>[\s\S]*?<\/thinking>/g, '')
}
```

#### 3. 状态持久化
- 使用 `localStorage` 保存用户的显示偏好
- 页面加载时自动恢复上次的设置
- 使用 `watch` 监听状态变化并保存

#### 4. 样式设计
添加了专门的CSS样式类：
- `.thinking-content`: 思考内容容器
- `.thinking-header`: 思考内容标题
- `.thinking-text`: 思考内容文本
- `.thinking-icon`: 思考图标

## 使用示例

### 用户视角

1. **开启思考显示**
   - 点击聊天界面右上角的"显示思考"开关
   - AI的回复会包含思考过程和最终答案
   - 思考过程以特殊样式显示

2. **关闭思考显示**
   - 关闭"显示思考"开关
   - AI的回复只显示最终答案
   - 思考过程被隐藏

### AI回复示例

```
<thinking>
用户询问了关于天气的问题。我需要：
1. 理解用户的具体需求
2. 考虑当前的时间和地点
3. 提供准确和有用的信息
</thinking>

今天天气晴朗，温度适宜，适合外出活动。建议您...
```

## 优势

1. **透明度**: 用户可以了解AI的思考过程，增加信任感
2. **教育性**: 展示AI的推理逻辑，帮助用户理解AI的工作方式
3. **灵活性**: 用户可以根据需要选择是否查看思考内容
4. **用户体验**: 特殊的视觉样式使思考内容易于识别
5. **持久化**: 记住用户的偏好设置

## 注意事项

1. **AI模型支持**: 需要AI模型能够理解并遵循思考标识的指令
2. **性能影响**: 思考内容会增加回复的长度，可能略微影响响应速度
3. **内容质量**: 思考内容的质量取决于AI模型的能力
4. **样式兼容**: 在不同设备和浏览器上测试样式显示效果

## 未来改进方向

1. **思考内容折叠**: 添加展开/折叠功能，节省屏幕空间
2. **思考内容高亮**: 对关键推理步骤进行高亮显示
3. **思考内容导出**: 允许用户导出思考过程用于学习
4. **多级思考**: 支持显示不同层次的思考深度
5. **思考统计**: 统计和分析AI的思考模式
