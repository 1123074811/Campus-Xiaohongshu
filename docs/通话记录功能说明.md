# 通话记录功能说明

## 功能概述

在WebRTC音频通话功能基础上，新增了通话记录功能。当用户进行语音通话时，系统会自动记录通话信息并保存到数据库中。

## 主要功能

### 1. 自动记录通话
- 当通话成功建立连接后开始计时
- 通话结束时自动保存通话记录
- 记录包含通话时长信息

### 2. 通话记录格式
- **消息类型**: `通话记录`
- **消息内容**: `通话时间：MM:SS` (例如：通话时间：03:45)
- **时间戳**: 通话结束时的时间
- **参与者**: 发起方和接听方

### 3. 显示样式
- 通话记录在聊天界面中以特殊样式显示
- 包含电话图标和通话时长信息
- 区分发起方和接听方的显示颜色

## 技术实现

### 前端实现

#### 1. 通话状态管理
```javascript
const callStatus = ref('') // 'calling', 'ringing', 'connected', 'ended'
const callStartTime = ref(null) // 通话开始时间
const callDuration = ref(0) // 通话时长（秒）
```

#### 2. 通话记录保存
```javascript
const saveCallRecord = () => {
  if (callStatus.value === 'connected' && callDuration.value > 0) {
    const callRecord = {
      text: `通话时间：${formatCallDuration(callDuration.value)}`,
      type: '通话记录',
      time: new Date().toLocaleString('zh-cn'),
      fromUserId: account.value.id,
      toUserId: chatUser.value.id,
      isRead: false
    }
    
    saveMessage(callRecord)
    createMessage(callRecord)
  }
}
```

#### 3. 触发时机
- 用户主动结束通话时
- 对方结束通话时
- 只有成功建立连接的通话才会保存记录

### 后端处理

通话记录使用现有的聊天消息存储机制：
- 消息类型设置为 `通话记录`
- 消息内容包含通话时长
- 存储到 `chat` 相关数据表中

## 使用场景

### 1. 通话历史查看
用户可以在聊天记录中查看历史通话信息：
- 通话发生的时间
- 通话持续时长
- 通话参与者

### 2. 通话统计
可以基于通话记录进行统计分析：
- 通话频率
- 通话时长统计
- 用户活跃度分析

## 注意事项

### 1. 记录条件
- 只有成功建立WebRTC连接的通话才会保存记录
- 被拒绝或未接听的通话不会生成记录
- 通话时长必须大于0秒

### 2. 时长计算
- 从双方成功建立连接开始计时
- 到任意一方结束通话为止
- 精确到秒级

### 3. 存储机制
- 使用现有的聊天消息存储系统
- 通话记录作为特殊类型的消息存储
- 支持消息的所有基础功能（时间戳、已读状态等）
