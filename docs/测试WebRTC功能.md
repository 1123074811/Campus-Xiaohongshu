# 响应式设计测试指南

## 测试环境准备

### 1. 启动开发服务器
```bash
cd vue
npm run dev
# 或
yarn dev
```

### 2. 访问测试页面
- 聊天页面: `http://localhost:5173/front/chat`
- 响应式演示页面: `http://localhost:5173/front/responsive-demo`

## 响应式测试步骤

### 1. 浏览器开发者工具测试

#### Chrome DevTools
1. 按 F12 打开开发者工具
2. 点击设备模拟器图标 (📱)
3. 选择不同设备进行测试：
   - iPhone SE (375×667)
   - iPhone 12 Pro (390×844)
   - iPad (768×1024)
   - iPad Pro (1024×1366)
   - 自定义尺寸

#### Firefox 响应式设计模式
1. 按 F12 打开开发者工具
2. 点击响应式设计模式图标
3. 测试不同屏幕尺寸

### 2. 聊天页面测试要点

#### 桌面端 (>1024px)
- ✅ 用户列表在左侧，宽度 280px
- ✅ 聊天区域在右侧，占据剩余空间
- ✅ 消息气泡最大宽度 60%
- ✅ 头像尺寸 42px/40px
- ✅ 通话按钮正常显示

#### 平板端 (768px-1024px)
- ✅ 用户列表宽度缩小至 250px
- ✅ 消息气泡最大宽度 70%
- ✅ 头像尺寸 36px/35px
- ✅ 按钮和文字适当缩小

#### 移动端 (≤768px)
- ✅ 布局变为垂直排列
- ✅ 用户列表占据上方 40% 高度
- ✅ 聊天区域占据下方 60% 高度
- ✅ 消息气泡最大宽度 75%
- ✅ 头像尺寸 32px/30px

#### 小屏手机 (≤480px)
- ✅ 用户列表占据 35% 高度
- ✅ 聊天区域占据 65% 高度
- ✅ 表情面板适配小屏幕
- ✅ 按钮和文字进一步缩小

### 3. 表情面板测试

#### 不同屏幕尺寸下的表现
- **桌面端**: 500×320px, 8列网格
- **平板端**: 400×280px, 6列网格
- **移动端**: 300×240px, 5列网格

#### 测试步骤
1. 点击输入框右侧的表情按钮 😊
2. 检查表情面板是否正确显示
3. 测试不同分类切换
4. 验证表情选择功能
5. 检查点击外部关闭功能

### 4. 视频通话界面测试

#### 测试步骤
1. 选择一个在线用户
2. 点击"视频通话"按钮
3. 检查视频通话界面适配

#### 不同屏幕的表现
- **桌面端**: 最大宽度 1000px
- **平板端**: 95% 宽度
- **移动端**: 全屏显示

#### 本地视频窗口
- **桌面端**: 200×150px
- **平板端**: 150×112px
- **移动端**: 120×90px

## 问题排查

### 常见问题
1. **布局错乱**: 检查 CSS 媒体查询是否正确
2. **按钮太小**: 确保最小点击区域 44×44px
3. **文字模糊**: 检查字体大小和 DPI 设置
4. **滚动卡顿**: 优化 CSS 动画和 JavaScript

### 调试工具

- Firefox Developer Tools
- Safari Web Inspector
- Vue DevTools
