# 测试后台AI助手管理功能

## 测试准备

### 1. 数据库准备
确保已执行AI助手初始化SQL脚本：
```sql
-- 执行初始化脚本
source springboot/sql/init_ai_assistant.sql;

-- 验证表创建
SHOW TABLES LIKE 'ai_%';
SELECT * FROM ai_assistant_config;
```

### 2. 应用启动
1. 启动Spring Boot后端应用
2. 启动Vue前端应用
3. 确保Redis服务正在运行
4. 确保Ollama服务正在运行（如果测试AI功能）

### 3. 测试账号
使用管理员账号登录系统，确保账号具有`ROLE_ADMIN`权限。

## 功能测试步骤

### 1. 访问管理界面

#### 测试步骤：
1. 以管理员身份登录系统
2. 进入后台管理界面（`/back/home`）
3. 查看左侧菜单是否显示"AI助手管理"选项
4. 点击"AI助手管理"菜单项

#### 预期结果：
- 菜单项正常显示（带有机器人图标）
- 点击后跳转到`/back/aiAssistant`页面
- 页面正常加载，显示AI助手管理界面

### 2. 统计数据测试

#### 测试步骤：
1. 进入AI助手管理页面
2. 观察页面顶部的统计卡片区域
3. 检查四个统计指标是否正常显示

#### 预期结果：
- 显示"总会话数"、"总消息数"、"活跃用户"、"今日会话"四个统计卡片
- 数值正确显示（初始状态可能为0）
- 卡片样式美观，图标正确显示

### 3. 会话管理测试

#### 3.1 会话列表显示
**测试步骤：**
1. 点击"会话管理"选项卡
2. 查看会话列表表格

**预期结果：**
- 表格正常显示，包含会话ID、标题、用户、消息数、时间等列
- 如果没有数据，显示空状态
- 分页组件正常显示

#### 3.2 搜索功能测试
**测试步骤：**
1. 在搜索框中输入关键词
2. 选择日期范围
3. 点击"搜索"按钮

**预期结果：**
- 搜索结果正确筛选
- 清空搜索条件后恢复全部数据
- 搜索过程中显示加载状态

#### 3.3 会话操作测试
**测试步骤：**
1. 点击某个会话的"查看消息"按钮
2. 点击某个会话的"删除"按钮
3. 选择多个会话，点击"批量删除"

**预期结果：**
- "查看消息"打开对话框，显示完整的对话记录
- "删除"操作弹出确认对话框，确认后删除成功
- "批量删除"正确删除选中的会话

### 4. 消息管理测试

#### 4.1 消息列表显示
**测试步骤：**
1. 点击"消息管理"选项卡
2. 查看消息列表表格

**预期结果：**
- 表格显示会话ID、用户、类型、内容、时间等信息
- 用户消息和AI回复用不同的标签区分
- 长消息内容正确截断显示

#### 4.2 消息筛选测试
**测试步骤：**
1. 使用消息类型下拉框筛选
2. 输入关键词搜索消息内容
3. 选择日期范围筛选

**预期结果：**
- 筛选结果正确
- 多个筛选条件可以组合使用
- 清空筛选条件恢复全部数据

#### 4.3 消息详情测试
**测试步骤：**
1. 点击某条消息的"详情"按钮
2. 查看消息详情对话框

**预期结果：**
- 对话框正确显示消息的完整内容
- 如果是AI回复且包含思考内容，正确显示思考过程
- 显示消息的元信息（时间、用户等）

### 5. 系统配置测试

#### 5.1 配置加载测试

#### 5.3 配置重置测试

### 6. 权限控制测试

#### 测试步骤：

## API接口测试

### 1. 统计数据接口
```bash
curl -X GET "http://localhost:9090/admin/ai/stats" \
  -H "token: YOUR_ADMIN_TOKEN"
```

### 2. 会话列表接口
```bash
curl -X GET "http://localhost:9090/admin/ai/sessions?page=1&size=20" \
  -H "token: YOUR_ADMIN_TOKEN"
```

### 3. 消息列表接口
```bash
curl -X GET "http://localhost:9090/admin/ai/messages?page=1&size=20" \
  -H "token: YOUR_ADMIN_TOKEN"
```

### 4. 配置接口
```bash
# 获取配置
curl -X GET "http://localhost:9090/admin/ai/config" \
  -H "token: YOUR_ADMIN_TOKEN"

# 保存配置
curl -X POST "http://localhost:9090/admin/ai/config" \
  -H "Content-Type: application/json" \
  -H "token: YOUR_ADMIN_TOKEN" \
  -d '{"modelName":"deepseek-r1:7b","maxMessages":30}'
```

## 常见问题排查

### 1. 菜单不显示
- 检查用户权限是否为ROLE_ADMIN
- 检查路由配置是否正确
- 检查图标导入是否正确

### 2. 数据加载失败
- 检查后端服务是否正常运行
- 检查数据库连接是否正常
- 检查API接口是否正确

### 3. 配置保存失败
- 检查数据库表是否存在
- 检查配置项格式是否正确
- 检查权限验证是否通过

### 4. 思考内容不显示
- 检查消息内容是否包含thinking标签
- 检查前端格式化函数是否正确
- 检查CSS样式是否加载
