# WebRTC TURN服务器解决方案总结

## 问题描述

在Linux服务器环境中，由于严格的网络配置和防火墙限制，STUN服务器无法有效穿透NAT，导致WebRTC音视频通话连接失败。

## 解决方案

通过部署TURN（Traversal Using Relays around NAT）服务器作为中继解决方案，确保在无法建立直接P2P连接时提供数据转发服务。

## 使用步骤

```bash

```

### 2. 前端配置
```bash
# 复制环境变量模板
cp vue/.env.example vue/.env.local

# 编辑配置文件，填入TURN服务器信息
```

## 网络架构

```
客户端A ←→ STUN服务器 (NAT穿透)
    ↓
客户端A ←→ TURN服务器 ←→ 客户端B (中继转发)
```

## 部署环境要求

### 服务器要求
- **操作系统**: Ubuntu 18.04+ / CentOS 7+
- **内存**: 最小1GB，推荐2GB+
- **带宽**: 根据并发用户数配置
- **端口**: 3478(UDP/TCP), 5349(TCP), 49152-65535(UDP)

### 网络要求
- **公网IP**: 必需
- **防火墙**: 正确配置端口开放
- **域名**: 推荐配置（SSL证书需要）
