# Element Plus 图标修复说明

## 问题描述
在实现WebRTC音频通话功能时，遇到了Element Plus图标导入错误：
```
SyntaxError: The requested module does not provide an export named 'MicrophoneSlash'
```

## 解决方案

### 1. 图标名称修正
将不存在的图标名称替换为正确的Element Plus图标：

**修改前：**
```javascript
import {MicrophoneSlash, PhoneOutlined} from '@element-plus/icons-vue'
```

**修改后：**
```javascript
import {MuteNotification, Phone} from '@element-plus/icons-vue'
```

### 2. 模板中的图标使用
**修改前：**
```vue
:icon="isMuted ? MicrophoneSlash : Microphone"
:icon="PhoneOutlined"
```

**修改后：**
```vue
:icon="isMuted ? MuteNotification : Microphone"
:icon="Phone"
```

## Element Plus 常用音频/通话相关图标

### 可用图标列表
- `Microphone` - 麦克风图标
- `MuteNotification` - 静音图标
- `Phone` - 电话图标
- `Close` - 关闭图标
- `VideoCamera` - 摄像头图标
- `VideoCameraFilled` - 实心摄像头图标

### 图标使用示例
```vue
<template>
  <!-- 麦克风控制 -->
  <el-button :icon="isMuted ? MuteNotification : Microphone">
    {{ isMuted ? '取消静音' : '静音' }}
  </el-button>
  
  <!-- 通话按钮 -->
  <el-button :icon="Phone" type="primary">
    语音通话
  </el-button>
  
  <!-- 结束通话 -->
  <el-button :icon="Close" type="danger">
    结束通话
  </el-button>
</template>
```

在浏览器中访问应用，检查图标是否正确显示。

## 注意事项

1. **图标名称大小写敏感**：确保图标名称的大小写完全正确
2. **版本兼容性**：不同版本的Element Plus可能有不同的图标集
3. **按需导入**：只导入实际使用的图标，避免打包体积过大

## 常见图标替代方案

| 功能 | 推荐图标 | 备选图标 |
|------|----------|----------|
| 麦克风开启 | `Microphone` | `VideoCamera` |
| 麦克风静音 | `MuteNotification` | `Close` |
| 发起通话 | `Phone` | `VideoCamera` |
| 结束通话 | `Close` | `SwitchButton` |
| 视频通话 | `VideoCamera` | `VideoCameraFilled` |

修复完成后，WebRTC音频通话功能应该能够正常运行，所有图标都能正确显示。
