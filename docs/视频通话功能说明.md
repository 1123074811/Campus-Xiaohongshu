# 视频通话功能说明

## 功能概述

在现有语音通话功能基础上，新增了视频通话功能。用户可以与在线好友进行实时视频通话，支持摄像头控制、静音控制等功能。

## 主要功能

### 1. 发起视频通话
- 在聊天界面右上角点击"视频通话"按钮
- 自动请求摄像头和麦克风权限
- 显示专用的视频通话界面

### 2. 接听视频通话
- 收到视频通话邀请时显示特殊标识
- 可以选择接听或拒绝视频通话
- 接听后自动开启摄像头和麦克风

### 3. 视频通话控制
- **静音/取消静音**: 控制麦克风开关
- **开启/关闭摄像头**: 控制视频流开关
- **通话时长显示**: 实时显示通话持续时间
- **结束通话**: 主动结束当前视频通话

### 4. 视频界面布局
- **主视频区域**: 显示对方的视频画面
- **小窗口**: 显示自己的视频画面
- **控制栏**: 底部显示通话控制按钮
- **全屏模式**: 支持全屏视频通话

#### 1. 共享的核心功能
- WebRTC连接建立和管理
- 信令服务器通信
- 通话状态管理
- 通话记录保存

#### 2. 扩展的视频功能
```javascript
// 媒体约束配置
const constraints = isVideo 
  ? { audio: true, video: true }  // 视频通话
  : { audio: true }               // 语音通话

// 通话类型标识
const callType = ref('audio') // 'audio' 或 'video'
```

#### 3. 统一的通话流程
```javascript
const startCall = async (isVideo = false) => {
  // 设置通话类型
  callType.value = isVideo ? 'video' : 'audio'
  
  // 获取对应的媒体流
  localStream = await navigator.mediaDevices.getUserMedia(constraints)
  
  // 根据类型显示不同界面
  if (isVideo) {
    showVideoCall.value = true
  }
}
```

### 视频流处理

#### 1. 本地视频流
```javascript
// 绑定到DOM元素
nextTick(() => {
  if (localVideoRef.value) {
    localVideoRef.value.srcObject = localStream
  }
})
```

#### 2. 远程视频流
```javascript
peerConnection.ontrack = (event) => {
  remoteStream = event.streams[0]
  if (isVideo) {
    nextTick(() => {
      if (remoteVideoRef.value) {
        remoteVideoRef.value.srcObject = remoteStream
      }
    })
  }
}
```

### 视频控制功能

#### 1. 摄像头控制
```javascript
const toggleVideo = () => {
  if (localStream && callType.value === 'video') {
    const videoTrack = localStream.getVideoTracks()[0]
    if (videoTrack) {
      videoTrack.enabled = !videoTrack.enabled
      isVideoOff.value = !videoTrack.enabled
    }
  }
}
```

#### 2. 音频控制（复用）
```javascript
const toggleMute = () => {
  if (localStream) {
    const audioTrack = localStream.getAudioTracks()[0]
    if (audioTrack) {
      audioTrack.enabled = !audioTrack.enabled
      isMuted.value = !audioTrack.enabled
    }
  }
}
```

## 用户界面

### 1. 通话按钮
- **语音通话按钮**: 蓝色电话图标
- **视频通话按钮**: 绿色摄像头图标
- 只有在线用户才能发起通话

### 2. 视频通话界面
```vue
<div class="video-call-container">
  <!-- 主视频区域 -->

  </div>
  
  <!-- 本地视频小窗口 -->
  <div class="local-video-container">
    <video ref="localVideoRef" class="local-video" autoplay playsinline muted></video>
  </div>
  
  <!-- 控制栏 -->
  <div class="video-call-controls">
    <div class="control-buttons">
      <el-button @click="toggleMute">静音</el-button>
```

## 故障排除

### 常见问题
1. **摄像头无法开启**: 检查浏览器权限设置
2. **视频卡顿**: 检查网络带宽和设备性能
3. **音视频不同步**: 检查设备驱动和浏览器版本
4. **黑屏问题**: 确认摄像头未被其他应用占用

### 调试方法
- 使用浏览器开发者工具查看媒体流状态
- 检查WebRTC连接统计信息
- 监控网络质量和延迟指标
