# 表情功能说明

## 功能概述

在聊天页面的文本输入框右侧添加了表情功能，用户可以快速插入原生Unicode emoji表情到消息中，丰富聊天体验。

## 主要功能

### 1. 表情按钮
- 位于文本输入框右侧
- 使用太阳图标（Sunny）表示
- 点击可打开/关闭表情面板

### 2. 表情面板
- **分类显示**: 按类别组织表情（笑脸、手势、心情、动物、食物、活动）
- **网格布局**: 8列网格显示，便于浏览选择
- **悬停效果**: 鼠标悬停时表情放大显示
- **滚动支持**: 支持垂直滚动查看更多表情

### 3. 表情分类
- **笑脸**: 各种笑脸和面部表情
- **手势**: 手部动作和手势
- **心情**: 爱心、符号等情感表达
- **动物**: 各种动物表情
- **食物**: 食物和饮品
- **活动**: 运动和活动相关

### 4. 交互功能
- 点击表情直接插入到文本框
- 支持连续选择多个表情
- 点击外部区域自动关闭面板
- 发送消息后自动关闭面板

## 技术实现

### 1. 数据结构
```javascript
const emojiCategories = ref([
  {
    name: '笑脸',
    key: 'smileys',
    emojis: ['😀', '😃', '😄', '😁', '😆', '😅', '🤣', '😂', ...]
  },
  // ... 其他分类
])
```

### 2. 状态管理
```javascript
const showEmojiPanel = ref(false)        // 控制面板显示
const activeEmojiCategory = ref('smileys') // 当前活跃分类
```

### 3. 核心方法
```javascript
// 切换表情面板
const toggleEmojiPanel = () => {
  showEmojiPanel.value = !showEmojiPanel.value
}

// 选择表情
const selectEmoji = (emoji) => {
  text.value += emoji
}

// 切换分类
const switchEmojiCategory = (categoryKey) => {
  activeEmojiCategory.value = categoryKey
}
```

### 4. 外部点击处理
```javascript
const handleClickOutside = (event) => {
  const emojiPanel = document.querySelector('.emoji-panel')
  const emojiButton = document.querySelector('.emoji-button')
  
  if (emojiPanel && emojiButton && 
      !emojiPanel.contains(event.target) && 
      !emojiButton.contains(event.target)) {
    showEmojiPanel.value = false
  }
}
```
